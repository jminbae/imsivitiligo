# SEO·AEO·GEO 점검 기록

## 유지한 검색 표면

- 기존 canonical·hreflang·breadcrumb·MedicalWebPage·FAQPage·reviewer 연결은 수정하지 않았습니다.
- 엑시머 페이지의 기존 Service 구조화 데이터 범위를 넓히지 않았습니다.
- 새 내부 링크는 언어 경로 헬퍼를 사용해 `/ko/` 및 향후 다국어 경로 규칙을 따릅니다.
- 기존 카테고리명과 URL을 바꾸지 않았습니다.

## 강화한 답변 표면

- 질문형 H2와 짧은 직접 답변을 함께 배치했습니다.
- 세부 답은 H3와 순서 있는 목록으로 구성해 사람과 검색 시스템이 판단 기준을 빠르게 찾도록 했습니다.
- 활동성, 치료 단계, 부위별 반응, 수술 후 경과, 탈색치료 결정, 생활관리처럼 환자가 실제로 이어서 묻는 질문을 기존 페이지 문맥 안에 배치했습니다.
- 새 내용을 FAQ 스키마에 억지로 복제하지 않아 화면과 구조화 데이터의 불일치를 만들지 않았습니다.

## 의료 콘텐츠 원칙

- 원고에서 근거가 확인되는 범위만 사용했습니다.
- 수치·기간·성공률을 새로 단정하지 않았습니다.
- 치료 반응의 개인차와 의료진 평가 필요성을 명시했습니다.
- 음식, 미용 시술, 마음 건강은 공포나 금지 중심이 아니라 상담과 관찰 중심으로 설명했습니다.

## 검증

- `npx astro check --minimal`: 오류 0건
- 백반증 관련 계약 테스트: 212/212 통과
- 운영 업로드 이미지가 제외된 새 복제 폴더라 전체 `npm run build`는 기존 `clinic_content.json` 참조 이미지 무결성 검사에서 중단됩니다. 이번 변경 파일의 컴파일 오류가 아니라 로컬 운영 산출물 부재입니다.
- 랜딩 및 각 전용 컴포넌트의 추가 구간을 데스크톱 브라우저로 직접 렌더링해 명암·간격·앵커·링크를 확인했습니다.
