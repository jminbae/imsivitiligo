# 힐하우스피부과 백반증 정보 보강안

힐하우스피부과 백반증 페이지의 기존 카테고리·콘텐츠·디자인 구조를 유지하면서 환자가 치료 흐름과 판단 기준을 더 쉽게 이해하도록 보강한 검토용 저장소입니다.

## 보강 범위

- 백반증 메인: 상태에 따른 치료 선택 안내
- 백반증 소개: 활동성을 살펴보는 네 가지 단서
- 엑시머치료: 부위별 치료 반응 점검
- 약물치료: 활동기·회복기·유지기의 치료 목표
- 수술치료: 수술 후 생착과 색소 확산 관찰
- 탈색치료: 치료 전 확인해야 할 결정 기준
- 생활관리: 기록·피부 자극·식사·마음 건강
- 연구 소개: 환자의 질문에서 연구로 이어지는 탐색 경로

이번에 추가하거나 변경한 정보 구간은 기존 분위기를 유지하면서 제목만 브랜드 블루 계열로 구분했습니다.

## 검증

- 백반증 관련 계약 테스트 212개 통과
- Astro 검사 오류 0건·경고 0건
- 기존 H2 계층, URL, canonical, 구조화 데이터 유지
- 추가 제목 색상 WCAG AA 명암비 충족

## 참고

이 저장소는 기존 비공개 홈페이지 전체 소스를 공개하지 않기 위해 이번 백반증 보강에 관련된 변경 파일과 검토 문서만 분리한 리뷰용 스냅샷입니다. 단독 실행용 전체 프로젝트가 아니며, 실제 홈페이지 반영 전 의료 문구에 대한 책임 의료진의 최종 확인이 필요합니다.
